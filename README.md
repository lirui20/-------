# 文件批量重命名工具

一个基于 Python 和 Tkinter 的图形化文件批量重命名工具，支持多种重命名模式和灵活的筛选功能。

## 环境要求

- Python 3.6 或更高版本
- Tkinter（Python 标准库，通常已内置）

## 运行方式

```bash
python folder_renamer.py
```

## 功能介绍

### 重命名模式

工具提供 7 种重命名模式：

| 模式 | 说明 | 示例 |
|------|------|------|
| 添加前缀 | 在文件名前添加指定文本 | `photo.jpg` -> `2024_photo.jpg` |
| 添加后缀 | 在扩展名前添加指定文本 | `photo.jpg` -> `photo_backup.jpg` |
| 查找替换 | 替换文件名中的指定文本 | `old_file.txt` -> `new_file.txt` |
| 序号重命名 | 按模板和序号重命名 | `photo.jpg` -> `01_photo.jpg` |
| 正则替换 | 使用正则表达式替换 | 支持分组和反向引用 |
| 大小写转换 | 转换文件名大小写 | `Photo.jpg` -> `photo.jpg` |
| 删除字符 | 删除指定字符或内容 | `file (1).txt` -> `file.txt` |

### 序号重命名模板

序号重命名模式支持以下占位符：

- `{n}` - 序号（根据设置的位数自动补零）
- `{name}` - 原文件名（不含扩展名）
- `{ext}` - 原扩展名（含点号）

示例模板：
- `{n}_{name}` -> `01_photo.jpg`
- `{name}_{n}` -> `photo_01.jpg`
- `IMG_{n}{ext}` -> `IMG_01.jpg`

### 扩展名处理

- 勾选"保留原扩展名不变"：重命名操作只影响文件名部分
- 在"新扩展名"输入框填写扩展名：统一修改所有文件的扩展名

### 筛选条件

- 文件名包含：只显示文件名中包含指定文本的文件
- 文件名排除：排除文件名中包含指定文本的文件
- 扩展名筛选：只显示指定扩展名的文件，多个扩展名用逗号分隔（如 `.jpg,.png,.gif`）
- 包含隐藏文件：是否显示以点开头的隐藏文件
- 同时包含文件夹：是否将文件夹也纳入重命名范围

## 使用步骤

1. **选择目标文件夹**
   - 点击"浏览..."按钮选择包含待重命名文件的文件夹
   - 或直接在输入框中输入文件夹路径后点击"刷新"

2. **设置筛选条件**（可选）
   - 根据需要设置文件名包含/排除条件
   - 设置扩展名筛选（如只处理图片文件）

3. **选择重命名模式**
   - 在左侧面板选择需要的重命名模式
   - 根据所选模式填写相应参数

4. **设置扩展名处理方式**
   - 决定是否保留原扩展名
   - 如需统一修改扩展名，在对应输入框填写

5. **生成预览**
   - 点击"生成预览"按钮
   - 在右侧预览区查看重命名效果
   - 检查状态列，确保没有"重名冲突"或"非法字符"等问题

6. **执行重命名**
   - 确认预览无误后，点击"执行重命名"
   - 在弹出的确认对话框中点击"是"

## 状态说明

预览列表中的状态列含义：

| 状态 | 说明 |
|------|------|
| 待执行 | 可以正常执行重命名 |
| 无变化 | 新文件名与原文件名相同，将跳过 |
| 名称为空 | 新文件名为空，无法执行 |
| 重名冲突 | 与其他文件的新名称重复 |
| 非法字符 | 新文件名包含系统不允许的字符 |

## 其他功能

### 撤销操作

点击"撤销上次操作"可以恢复上一次批量重命名的所有文件。支持多次撤销。

### 导出日志

点击"导出日志"可将所有操作历史导出为 JSON 文件，便于记录和追溯。

## 注意事项

1. 执行重命名前请仔细检查预览结果
2. 建议在重要文件上操作前先备份
3. Windows 系统文件名不能包含以下字符：`< > : " / \ | ? *`
4. 如果文件正在被其他程序使用，重命名可能会失败

## 删除字符模式详解

删除字符模式提供以下选项：

- 删除指定字符：删除参数值中的每个字符
- 删除前N个字符：删除文件名开头的N个字符
- 删除后N个字符：删除文件名末尾的N个字符
- 删除数字：删除文件名中的所有数字
- 删除空格：删除文件名中的所有空格
- 删除括号及内容：删除各类括号及其中的内容，支持 `()` `[]` `{}` 以及中文括号 `()` `【】`

## 正则替换示例

| 需求 | 正则表达式 | 替换为 |
|------|-----------|--------|
| 删除文件名中的数字 | `\d+` | （留空） |
| 将下划线替换为连字符 | `_` | `-` |
| 删除括号及内容 | `\([^)]*\)` | （留空） |
| 提取括号中的内容 | `.*\(([^)]*)\).*` | `\1` |
| 将多个空格合并为一个 | `\s+` | ` ` |
